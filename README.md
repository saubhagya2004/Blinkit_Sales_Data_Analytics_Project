# 🛒 Blinkit Sales Dashboard (Power BI)

### 📊 Project Overview
This Power BI dashboard analyzes Blinkit sales data across multiple cities and categories.  
It helps track key metrics like total sales, profit, orders, and profit margin.

### 🔍 Key Insights
- Total Sales: 154K  
- Total Profit: 28K  
- Profit Margin: 18%  
- Monthly and Category-wise trends  
- City-wise performance  

### 🧩 Tools Used
- Power BI Desktop
- Excel (for data cleaning)
- DAX for calculated measures

### 📂 Files Included
- `Blinkit_Sales_Data_Analyst_Project.pbit` → Power BI template file  
- `Screenshot 2025-11-04 222132.png` → Dashboard preview  

### 🚀 How to Use
1. Download the `.pbit` file
2. Open it in Power BI Desktop
3. Load data if prompted
4. Explore the interactive visuals!
